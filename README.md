# ⚡ Console Mining Empire (CLI Tycoon Simulator)

Консольная экономическая стратегия и тайкун-симулятор управления криптовалютной фермой. Проект демонстрирует применение принципов ООП, чистой слоистой архитектуры (Layered Architecture), точных финансовых расчётов без использования чисел с плавающей точкой, сохранение игрового мира в JSON и покрытие бизнес-логики модульными тестами.

---

## 🛠 Стек технологий
* **Язык:** Java 17+
* **Сборка:** Apache Maven
* **Сериализация / JSON:** FasterXML Jackson (поддержка полиморфной сериализации сущностей)
* **Тестирование:** JUnit 5, Mockito

---

## 💡 Ключевые архитектурные и технические решения

1. **Точные финансовые операции (`BigDecimal`):**
   * Полный отказ от примитивов `double` и `float` во избежание накопления погрешностей стандарта IEEE 754.
   * Фиатный баланс (USD) рассчитывается с точностью до 2 знаков (`RoundingMode.HALF_UP`), криптовалюта (BTC) — до 8 знаков (Satoshi precision).

2. **Слоистая архитектура (Separation of Concerns):**
   * `domain` — независимые бизнес-модели, иерархия устройств (`MiningDevice` -> `GpuDevice`, `AsicDevice`) и неизменяемые спецификации (`Enum`).
   * `service` — изолированная бизнес-логика суточного цикла майнинга, расчёта тарифов энергосети, биржевых котировок и генерации случайных событий.
   * `repository` — сохранение и загрузка прогресса игрока в JSON через `ObjectMapper`.
   * `ui` / `Main` — консольное управление с защитой от аварийных падений и невалидного пользовательского ввода.

3. **Игровые механики:**
   * **Рынок и волатильность:** динамический пересчёт курса BTC с сохранением скользящей истории котировок.
   * **Износ и ремонт:** амортизация оборудования (1–3% в сутки), риск критической поломки при падении ресурса ниже 30%, механики ремонта и сдачи на б/у рынок.
   * **Ограничения помещений:** лимиты слотов и потребляемой мощности электросети (риск выбивания пробок), запрет на установку ASIC в жилой зоне.
   * **Случайные события:** рыночные пампы, криптозима, инспекции электросетей и ретро-дропы.
